# Démonstration entièrement fictive

Mira possède une carte, traverse un pont et rejoint Noa. Dans la révision, elle détruit la carte. Deux relations causales déclarées indiquent qu'elle franchit le pont grâce à la carte ou à une corde prête, puis retrouve Noa grâce à la traversée. La corde n'est pas prête dans cette version : la traversée et la rencontre exigent une relecture. Ce n'est pas une analyse automatique du sens littéraire.

Depuis la racine du dépôt, exécuter les deux commandes audit et compare figurant dans docs/NARRATIVE_INTELLIGENCE_ENGINE.md. Les sorties doivent rester dans un dossier local, pas dans les sources du livre.
